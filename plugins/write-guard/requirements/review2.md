## 5. 新发现 findings（均 LOW，非阻断）

### LOW-1 — FR-04 "8.3 短名"表述引用歧义
- **位置**：FR-04（可扩充等价形态举例）
- **问题**：第一轮 MED-2 中"8.3 短名"指 Windows 8.3 短文件名格式（旧式 8 字符名+3 字符扩展名的目录压缩形态）；但需求文档第 8 节仅 8.1/8.2 两个小节，FR-04 直接写"如 8.3 短名"易被误读为"文档第 8.3 节"（不存在）或与节号混淆。
- **建议**：改为"Windows 8.3 短文件名格式"并补一句形态示例说明，消除节号歧义。

### LOW-2 — 8.2 小节标题"未决项（开放）"与内容不符
- **位置**：8.2 小节标题
- **问题**：Q-07 是已向用户声明并获知情接受的边界记录（文档自注"非挂起问题"），Q-08 是流程兜底条款，二者均非"未决/开放"问题，置于"未决项（开放）"标题下语义自相矛盾。
- **建议**：小节标题改为"补充声明与兜底条款"，或将 Q-07 移入 8.1（其已决策、已知情），8.2 仅留 Q-08。

### LOW-3 — AC-10 可测试性表述可进一步精确
- **位置**：AC-10
- **问题**：轮询顺序 [C, A, B] 下 C 最先执行、命中即返，"令 A/B 抛异常后断言 C 仍按原行为命中"在单次调用中不会同帧发生（A/B 异常只在 C 未命中时才被触发）。当前一句话表述可能使设计阶段对测试桩构造产生歧义。
- **建议**：拆为两个明确断言组合：① C 命中调用返回 block，不受 A/B 存在与否影响（C 优先且独立）；② 仅 A（或仅 B）命中且被桩注入抛异常时，该项按未命中处理（放行）、异常日志有记录、插件不崩、后续调用正常（插件级不 fail-open）。

### LOW-4（说明性，可不改）— 待澄清项编号合并的可追溯性
