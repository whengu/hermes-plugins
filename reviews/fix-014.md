## §A 改动 A（F-13-S1）粘连入口全族接 _pair_unquote（工作树 L661-665/L719-721/L732-740/L795-801/L987-1013）

与 r13 改动B **严格同法同纪律**：仅匹配输入剥**成对**外层引号一处（判定视图），
token 化与 norm 链不经过（F-7-2 通用剥离禁令不回潮）；全部接点在复制/输出/写
目标命令门后，零扰动门外。四支接点：

1. **A1 `_GLUED_T_RE`**（L799-801 判定支 + L1013 收集支）：`_GLUED_T_RE.match(
   _pair_unquote(raw))`——`cp x "-t<DIR>"`/`install '-t<DIR>/'`/`-t=` 混粘与裸形
   同义（含守卫缴械向）。收集支 L1013 对 `_GLUED_T_RE` **无条件**剥（-t 族仅复制
   族 cmd 有语义，复制族门天然在场）；`_GLUED_O_RE` 维持 r13 的 `_ou` 门控形
   （复制族 cmd 不启用 -o 剥离，零扰动）。

   `_pair_unquote(raw).lower().startswith("--target-directory=")`——startswith
   锚先剥再判；收集支 `norm_raw = _raw_ou.split("=", 1)[1]`。
3. **A3 `of=` 前缀支**（L719-721 判定 + L993-994 收集）：
   `_pair_unquote(raw).lower().startswith("of=")` + `_DD_RE.search(before)` 门
   保持——`dd "of=<CFG>"` 引号整包覆写封堵（靶心含反缴械形 `of=<守卫源码>`）。
4. **A4 `_OUTPUT_FLAG_EQ_RE` 长形支**（L732-739）：判定支提取

   "--output=<CFG>"` 与 `--output-document=` 长形引号整包接管。

## §B 改动 B（Q13-A）_OUTPUT_QUOTED_RE 并 cluster 尾 o 支（工作树 L640-645）

落地（定义扩 1 支 + 注释 4 行，≤规格上限）：

```
_OUTPUT_QUOTED_RE = re.compile(
    r"[\x27\x22](?:-[oO]|--output(?:-document)?|[-]?[a-zA-Z]*[oO])[\x27\x22]\s*$")
```

要点（逐条对齐规格 §B）：
1. 现内容段限「仅选项词」的三支并列：`-[oO]`（r12 单 o/O 约束**不回退**）、
   `--output(?:-document)?`（长形）、新增 **cluster 尾 o 支**
   `[-]?[a-zA-Z]*[oO]`——引号内=cluster 字母串且**尾字母 o/O**，值走既有后随
   token 判定（`curl "-so" <CFG>` 与裸 `-so <CFG>` 同义，curl 8.1.2 活证 rc=0
   实写；质量路 Q13-A 立项依据）。
2. 字符类比照 `_OUTPUT_FLAG_RE` dash cluster 支同款；**单 dash 专属**（`[-]?`
   非 `[-]{1,2}`）——双 dash 与 `-O` 大写红线语义**不扩**（`curl -O <url>`
   红线向、`--http1.0` 数字尾均不受本支影响，_verify_r14 K14/TC-R12-18 面复核）。
3. 整支在 `_OUTPUT_FLAG_CMDS_RE` 门后（仅 curl/wget/sort 三门命令）——门外
   `grep "-o"`/`grep "-so"`/任意引号词 `" -H"` 零扰动（K9/K11/B6 锁 PASS）。
4. 判定式位置不变（L734-740 同 r12 or 支位），未新增判定支、未改门。

实测：T11 curl `"-so"`、T12 curl `"-sSo"`、T13 wget `"-qO"`、T14 sort `"-ro"`
→ **block**；T17 bash -c 载体内 `curl "-so" <CFG>` → block（载体剔除链复用）；
必测负例 T18 `curl "-oL" <CFG>` → PASS（尾字母 L 非 o 不命中，URL 语义不误伤）、
K9/K11 grep 门外 → PASS、`curl -H "Accept: o"` → PASS（引号词非 cluster 形）。
TC-R14-11/12/13/14 四条锁正反两面。

**教训固化句落点（规格 §N-4，已入 CHANGELOG round14 节）**：引号剥离类修复，
验收面必须扫**全族粘连入口**（-o / -t / --target-directory / of= / 冒号形 /
cluster+空格值），**逐分支翻转表 + 逐分支活证**——本轮 F-13-S1 的根因正是 r13
改动B 只接 `_GLUED_O_RE`、同族邻支未接的覆盖不对称。
